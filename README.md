# RADAZ — yeni ünvan

RADAZ-ın mənbə kodu, bütün əvvəlki buraxılışları, yeni versiyaları və Setup faylları **[drnaghiyev/RADAZ-D-COM](https://github.com/drnaghiyev/RADAZ-D-COM)** reposuna köçürülüb.

- [Son buraxılış](https://github.com/drnaghiyev/RADAZ-D-COM/releases/latest)
- [Bütün buraxılışlar](https://github.com/drnaghiyev/RADAZ-D-COM/releases)

Bu köhnə ünvanda yalnız əvvəl quraşdırılmış RADAZ proqramlarının avtomatik yenilənməsini qoruyan **0.2.27 keçid paketi** saxlanılır. Paket əsas repoda yayımlanmış 0.2.27 ilə eynidir. Onu tətbiq etdikdən sonra proqram bütün sonrakı yeniləmələri RADAZ-D-COM-dan yoxlayır.

Quraşdırılmış proqramda **Yardım → Yeniləmələri yoxla → Yenilə → Proqramı yenidən aç** seçin. Setup-ı yenidən quraşdırmaq lazım deyil; lokal arxiv və istifadəçi ayarları saxlanılır.

0.2.27-də OpenAI açarını **Yardım → AI ayarları → OpenAI API açarı → Yadda saxla** bölməsində daxil etmək olar. Açar Windows hesabına bağlı şifrəli şəkildə həmin kompüterdə saxlanılır.
