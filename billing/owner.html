RADAZ · Satıcı ayarları

Bu panel sizin kompüterinizdə açılır. Alıcının RADAZ proqramında görünmür. Qiymət: 10 AZN / ay.

Yaddaş yeri: OPEN-SELLER-SETTINGS.cmd ilə açın

Ayarları dəyişmək üçün billing/OPEN-SELLER-SETTINGS.cmd faylını açın. HTML faylını birbaşa açmaq kifayət etmir. Açılan terminal pəncərəsi işlək qalmalıdır.

Satıcı və bank rekvizitləri

AZN və USD hesabları ayrı saxlanılır. Rekvizitləri yazmaq avtomatik kart ödənişini aktiv etmir. Hesab məlumatları yalnız bu kompüterdə saxlanılır; müştəri Setup paketinə daxil edilmir.

Ödəniş üsulu

Kapital Bank rekvizitləri hazırlanıb. Avtomatik ödəniş bağlantısı hələ aktiv deyil. Bunun üçün bankdan internet-ekvayrinq müqaviləsi, rəsmi API sənədi və test hesabı alınmalıdır. USD hesabı verilməyibsə boş saxlanılır. Bankın API müraciət səhifəsi

Bu ünvanları Epoint satıcı kabinetində də qeyd edin. API açarları və endpoint merchant hesabınızdan götürülməlidir.

Satıcı hesabı təsdiqlənmədən və provayder sınağı keçmədən real ödəniş qəbul etməyin. Ayın qiyməti serverdə hesablanır, alıcı tərəfindən dəyişdirilmir.

Yadda saxladıqdan sonra ayrıca ödəniş serverini yenidən başladın. Bu paneli internetə açmayın. Hesab və gizli açar faylları GitHub-a və müştəri ZIP-inə daxil edilmir.
