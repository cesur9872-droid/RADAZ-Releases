RADAZ · WINDOWS 10/11, 64 BİT · VERSİYA 0.2.9

Quraşdırma, yeniləmə və CD/DVD import

Bu təlimat həm hazırda RADAZ işləyən kompüter, həm də yeni kompüter üçündür.

1. Hazırkı kompüteri yeniləyin

  1. Açıq müayinəni və cihazdan görüntü qəbulunu tamamlayın. Vacib hesabatları saxlayın.
  2. RADAZ-0.2.9-Setup.exe faylını açıb quraşdırmanı tamamlayın. Eyni Windows istifadəçi hesabından istifadə edin. Köhnə proqramı əvvəlcədən silmək lazım deyil.
  3. Köhnə lokal xidmət işləyirsə və ya CD/DVD yeniləmə xəbərdarlığı qalırsa, Windows-u bir dəfə yenidən başladın. Yenidən başlatmazdan əvvəl qəbul edən cihazda göndərişin bitdiyini yoxlayın.
  4. İş masasındakı yeni RADAZ qısayolunu açın. Köhnə layihə qovluğundakı START faylını və ya köhnə qısayolu açmayın.
  5. Brauzerdə http://localhost:5173 açılacaq. Köhnə interfeys görünürsə Ctrl+F5 basın.
Local Archive qorunur. Standart arxiv Documents\RADAZ-Archive qovluğundadır. Bu qovluğu silməyin. Node.js, Python və DICOM xidməti Setup-a daxildir; onları ayrıca quraşdırmaq lazım deyil.

2. Başqa kompüterə quraşdırın

  1. RADAZ-0.2.9-Setup.exe faylını USB yaddaşla və ya etibarlı paylaşma vasitəsi ilə digər kompüterə köçürün. Source code ZIP quraşdırıcı deyil.
  2. Windows 10/11 64-bit kompüterdə Setup-ı açın. Sonra iş masasındakı RADAZ qısayolunu başladın.
  3. Yeni kompüter öz lokal arxivi və lisenziya vəziyyəti ilə başlayır. Əvvəlki kompüterin pasiyentləri avtomatik köçürülmür.
  4. CD/DVD-ni həmin kompüterin daxili və ya USB optik oxuyucusuna taxın. Disk File Explorer-də görünməlidir.
  5. RADAZ-da CD/DVD import düyməsini bir dəfə aktiv edin. Lokal ünvanı istifadə edin: localhost:5173. Başqa kompüterin IP-si ilə açılan RADAZ həmin server kompüterin diskini oxuyur.

3. CD/DVD necə açılır?

CD/DVD import aktiv olduqda proqram taxılmış və sonradan taxılan diski özü aşkar edir. DICOMDIR varsa onu oxuyur, sonra qovluqlardakı DICOM görüntülərini tapır. DICOMDIR olmayan disk də avtomatik skan edilir. Faylda .dcm uzantısı tələb olunmur. Upload, qovluq seçimi və təsdiq pəncərəsi açılmır.

Seriya tapılan kimi solda görünür. İlk kəsit hazır olanda seriyaya klik edib baxmağa başlayın; qalan görüntülər yüklənir. Series panelinin altında real say və faiz göstərilir. Disk hələ skan edilirsə ümumi say məlum olmadığından faiz əvəzinə skan vəziyyəti görünür. Yükləmə bitəndə progressbar gizlənir.

CD/DVD müayinəsi Local Archive-a yazılmır. Disk çıxarılanda həmin müayinənin açıq görüntüləri, MPR/3D volume və müvəqqəti cache silinir. Davam etmək üçün diski yenidən taxın.

5. Xəbərdarlıq qalırsa

“RADAZ və lokal xidməti yeni Setup ilə yeniləyin” yazısı adətən yeni interfeysin köhnə lokal xidmətə qoşulduğunu göstərir. İşləri saxlayın, Setup-ı quraşdırın, Windows-u yenidən başladın və yalnız yeni RADAZ qısayolunu açın.

Yoxlama üçün interfeys versiyası və lokal xidmət statusu açıla bilər. Birincidə version: 0.2.9, ikincidə appVersion: 0.2.9 gözlənilir. Xidmət statusunda appVersion yoxdursa köhnə xidmət işləyir.

Disk tapılmırsa onun File Explorer-də göründüyünü, optik oxuyucunun işlədiyini və CD/DVD import-un aktiv olduğunu yoxlayın. Fiziki disk çıxarılandan sonra görüntülərin bağlanması normaldır.

6. Rentgen / CR cihazı olan iş yeri

Hazırda uğurla işləyən CR → RADAZ göndəriş ayarlarını dəyişməyin. Yeniləmədən sonra Local Archive bölməsində qəbul xidmətinin işlədiyini yoxlayın. Başqa kompüterdə CR qəbulu qurulacaqsa həmin kompüterin IP ünvanı, RADAZ AE Title və qəbul portu cihazın göndəriş siyahısına ayrıca yazılmalıdır; köhnə kompüterin IP-sini olduğu kimi köçürməyin.

7. Satıcı üçün Kapital Bank

Satıcı panelində Kapital Bank, AZN hesabı və ayrıca USD hesabı sahələri var. Bu rekvizitlər yalnız satıcı kompüterində saxlanır və müştərinin Setup paketinə daxil edilmir. USD IBAN təqdim olunmadıqda boş qalır.

Bank rekvizitləri avtomatik kart ödənişi yaratmır. Avtomatik ödəniş üçün Kapital Bank / Birbank Biznes ilə internet-ekvayrinq müraciəti, bankın rəsmi inteqrasiya sənədi və test hesabı tələb olunur. Rəsmi API müraciət qaydası. API açarlarını yalnız lokal satıcı ayarları və ya serverin gizli ayarlarında saxlayın.
