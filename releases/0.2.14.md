RADAZ 0.2.14: MPR/3D düzəlişləri və GitHub yükləmə xətasına avtomatik təkrar cəhd.

**Windows 10/11 64-bit üçün RADAZ-0.2.14-Setup.exe endirin.** Quraşdırılmış RADAZ-da **Yardım → Yeniləmələri yoxla → Yenilə** istifadə edin. Yenilənmə progressbarda göstərilir, hazır paket növbəti açılışda tətbiq olunur.

- GitHub fayl serveri müvəqqəti 500/502/503/504 qaytardıqda yükləyici köhnə xəta cavabını təkrar istifadə etmədən üç dəfəyə qədər cəhd edir. Paket ölçüsü, SHA-256 və daxili manifest yenə yoxlanılır.
- MPR-də qalınlıq/rejim dəyişməsi fiziki koordinatları, lokalizerin kəsişməsini, zoom və mövqeyi qoruyur. Fırlatma yalnız uyğun müstəvini yenidən qurur; aksial zoom dəyişmir.
- Lokalizerin hər iki tərəfində kursoru izləyən fırlatma dairələri və fırlatma kursoru var. İki kliklə böyüdülən paneldə də lokalizer işləyir.
- 3D-də GPU imkan verəndə orijinal həcm saxlanılır. Ölçünü azaltmaq lazım gəldikdə bütün kəsitlər çəkili hesablamaya daxil edilir; kəsit atlama, sahənin kəsilməsi və geometriya sürüşməsi aradan qaldırılıb.
- Lisenziya yoxlanarkən pəncərə yanıb-sönmür; avtomatik aktivləşdirmə pəncərəsi yalnız müddət bitdikdə açılır.
- Başlıq düymələri bir sətirdədir. Dar ekranda yazılar gizlənir, çox dar ekranda alətlər sətri üfüqi sürüşdürülür. Filtr menyuları tam görünür.

0.2.13-dəki bütün düzəlişləri ehtiva edir. Yoxlamalar: MPR koordinatları/zoom/fırlatma, böyüdülmüş panel, bütün kəsitlərlə oblique HU volume, 76 kəsitli açıq CT, 700 kəsitli mərhələli idxal, lisenziya gecikməsi, 1920–390 px başlıqlar, oflayn quraşdırma və geri qaytarma.

Lokal arxiv ayrıca saxlanılır. İlkin sınaq buraxılışıdır; 3D detalı mənbə DICOM seriyasının kəsit aralığından da asılıdır.
