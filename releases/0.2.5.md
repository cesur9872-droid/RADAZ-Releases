RADAZ 0.2.5 Windows-da lokal serverin açılışını düzəldir.

- Lokal proqram birbaşa Node.js ilə işləyir; Cloudflare/Miniflare işçi prosesinə ehtiyac qalmır.
- START-RADAZ mənbə qovluğunda cari kodu yığıb hazır tətbiqi açır. Release ZIP-də hazır fayllar dərhal başladılır.
- Brauzer yalnız uyğun versiya uğurla açıldıqdan sonra göstərilir; uğursuz açılışdan sonra gözləmə prosesi dayandırılır.
- GitHub buraxılışı real server açılışı, əsas səhifələr, JavaScript faylları və arxiv bağlantısı sınaqlarını da keçir.
- 0.2.4-dəki kiçik monitor və CR qəbul ayarları düzəlişləri daxildir.

**RADAZ-0.2.5-Windows-preview.zip** faylını Assets bölməsindən endirin. Köhnə RADAZ serverini bağlayın, ZIP-i ayrıca qovluğa çıxarın, **SETUP-RADAZ.cmd**, sonra **START-RADAZ.cmd** başladın. Mövcud arxiv ayrıca `Documents\RADAZ-Archive` qovluğunda saxlanılır.
