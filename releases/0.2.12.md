RADAZ 0.2.12: ölçmə, mouse idarəsi və Windows yenilənmə düzəlişi.

**Windows 10/11 64-bit üçün RADAZ-0.2.12-Setup.exe endirin.** Artıq quraşdırılmış RADAZ-da **Yardım → Yeniləmələri yoxla → Yenilə** istifadə edin.

- Windows progress faylını müvəqqəti kilidlədikdə yenilənmə dayanmır: atomik yazma qısa fasilələrlə təkrar edilir. Yükləmə faizi, komponentlərin quraşdırılması və yekun təsdiq görünür.
- Yeni versiya bildirişi və **Yenilənməyə bax** düyməsi eyni prosesin gedişini açır. Hazır versiya növbəti RADAZ açılışında tətbiq olunur; lokal arxiv ayrıca saxlanılır.
- Deviasiya iki nöqtə ilə üfüqi xəttə görə bucağı və şaquli **H** hündürlüyünü göstərir. Ayaq tağında **H** və **°** işarələri istifadə olunur.
- Daha incə xətlər, böyük məlumat yazıları, xətt üzərində əl kursoru və ayrı hover/selection rəngləri. Uzunluq ölçüsündə hər iki ucdakı X marker çəkilmə zamanı da görünür.
- Ox üçün əlavə və dəyişdirilə bilən şərh. Qısa sağ klikdə **Sil** və cari kəsitdə hamısını silmək; **Ctrl+D** yalnız aktiv kəsitdəki ölçüləri və çəkilmiş xətləri silir.
- İlkin 2D/MPR idarəsi: sol düymə WW/WL, orta düymə move, sağ düyməni sürükləmək zoom. Brauzerin standart sağ klik menyusu söndürülüb. 3D-də sol düymə fırlatma, orta düymə move, sağ düymə zoom.
- MPR və 3D ayrıca vərəqələrdə açılır, eyni decode edilmiş piksel buferlərini paylaşır. CT Bone rənglənməsi, işıqlandırılması və son render keyfiyyəti yaxşılaşdırılıb; MRT üçün ayrıca intensivlik rejimi saxlanılıb.

Setup Node.js, Python, DICOM paketləri və FFmpeg-i daxil edir. 0.2.9 və daha köhnə quraşdırmalarda yeni yenilənmə kanalına keçmək üçün Setup-ı bir dəfə açın. Source code ZIP quraşdırıcı deyil.

İlkin sınaq buraxılışıdır. Vizual nəticə ilkin DICOM seriyasının keyfiyyətindən və kəsit qalınlığından asılıdır.
