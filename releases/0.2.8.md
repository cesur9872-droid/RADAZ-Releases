RADAZ 0.2.8 Windows quraşdırıcısı, avtomatik yeniləmə və diskdən mərhələli DICOM oxuma əlavə edir.

**Yeni kompüter üçün `RADAZ-0.2.8-Setup.exe` faylını endirib açın.** Quraşdırıcı Node.js, Python, DICOM paketləri, Pillow və FFmpeg-i özündə saxlayır. Ayrıca Node/Python/pnpm quraşdırılması və ilkin quraşdırma zamanı internet tələb olunmur. Windows 10/11, 64 bit üçündür.

- İş masasında və Başlat menyusunda RADAZ qısayolu yaradılır. Ona kliklədikdə lokal server və arxiv xidməti arxa planda başlayır, RADAZ brauzerdə açılır.
- Setup ilə quraşdırıldıqdan sonra yeni GitHub buraxılışları avtomatik yoxlanır və arxa planda endirilir. Hazır yeniləmə bildirişi görünür; işinizi bitirib qısayolu yenidən açanda yeni versiya tətbiq olunur. Müayinə zamanı proqram qəfil bağlanmır.
- SHA-256 və bütün paket faylları yoxlanmadan yeniləmə tətbiq edilmir. Yeni server açıla bilməzsə əvvəlki versiya bərpa edilir. Aktiv DICOM qəbulu, çap və ixrac zamanı arxiv yeniləməsi təxirə salınır.
- Arxiv və lisenziya proqramın qovluğundan ayrı saxlanılır. Yeniləmə pasiyent görüntülərini silmir.
- Əvvəlki ZIP versiyasından ilk keçiddə köhnə arxiv xidməti açıqdırsa, Windows-u bir dəfə yenidən başladıb iş masasındakı RADAZ qısayolundan açın. Sonrakı Setup versiyaları arxiv xidmətini də özləri yeniləyir.
- Viewer-də ayrıca **CD/DVD import** düyməsi optik diski avtomatik aşkar edir. DICOMDIR və ya bütün alt qovluqlar oxunur; uzantısız/raw DICOM da tanınır. Upload və qovluq seçimi istənilmir.
- Seriya və ilk thumbnail bütün fayllar bitməmiş göstərilir. İstifadəçi kəsitlərə baxarkən yükləmə arxa planda davam edir; seçilmiş kəsit saxlanılır. MPR/3D tam seriya hazır olduqda açılır.
- CD/DVD müayinələri Local Archive-a yazılmır. Disk çıxarılanda Viewer, MPR, 3D və hesabatda həmin diskin müvəqqəti görüntüləri və cache təmizlənir. Digər arxiv müayinələri saxlanılır.
- Sıxılmış DICOM üçün JPEG, JPEG-LS, JPEG 2000 və RLE dekoderləri paketdədir; internetdən codec yüklənmir.

Yeniləmə üçün GitHub buraxılışı giriş tələb etmədən əlçatan olmalıdır. Şəxsi depo buraxılışları alıcıların avtomatik yeniləmə mənbəyi kimi işləmir.

Alternativ: `RADAZ-0.2.8-Windows-x64.zip` tam oflayn paketidir; çıxarıb `SETUP-RADAZ.cmd` açmaq eyni qısayolları və avtomatik yeniləməni quraşdırır. `Windows-preview.zip` əvvəlki yüngül paketdir və sistemdə Node/Python tələb edir.
