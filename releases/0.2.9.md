RADAZ 0.2.9 CD/DVD import, MPR və Viewer idarəetməsini yeniləyir.

**Windows 10/11 64-bit üçün RADAZ-0.2.9-Setup.exe faylını quraşdırın.** Node.js, Python, DICOM və digər lokal runtime paketləri daxildir. Əvvəlki ZIP versiyasının lokal xidməti açıq qalıbsa, işinizi tamamlayıb Windows-u bir dəfə yenidən başladın və iş masasındakı yeni RADAZ qısayolunu açın. Local Archive saxlanılır.

- Series panelinin altında DICOM, arxiv və PACS yüklənməsi üçün real fayl sayı və progressbar; CD/DVD skanı zamanı naməlum ümumi say ayrıca göstərilir. Yükləmə bitəndə progressbar gizlənir.
- MPR-də yüklənən CT/MR seriyasının hazır aksial görüntüsü əvvəl açılır. Koronal və sagittal müstəvilər ayrı hazır olur və viewport üzərində hazırlıq gedişi göstərilir.
- 3D volume hazırlanması, GPU teksturası və ilk render tamamlanması faktiki mərhələlərlə göstərilir.
- MPR kəsişmə tutacağı DICOM world koordinatları ilə digər müstəviləri hərəkət etdirir. Xəttin özündən tutmaq həmin müstəvini translasiya edir; fırlatma tutacağı yalnız seçilən xətti və onun oblique rekonstruksiyasını dəyişir.
- Ölçülər üçün vahid normal, hover, selected və drawing rəngləri. Length uclarında çəkilmə zamanı da görünən, ekranda sabit ölçülü X markerlər.
- Local Archive-də hər müayinə ayrıca Viewer vərəqəsində açılır. F11 yalnız görüntü üzərində tam ekran əməliyyatıdır.
- MPR/3D-də logo render edilmir. Demo pasiyent və DICOM faylları production paketindən çıxarılıb; yalnız test fixtures içindədir.
- CD/DVD xəta mesajında bu və digər kompüterlər üçün quraşdırma təlimatına keçid var.
- Satıcı ayarlarında Kapital Bank üçün ayrıca AZN/USD hesab sahələri əlavə edilib. Rekvizitlər avtomatik ödəniş bağlantısı yaratmır; Kapital Bank API inteqrasiyası ayrıca bank sənədləri və test hesabı tələb edir. Satıcı rekvizitləri müştəri paketinə daxil edilmir.

CD/DVD müayinələri müvəqqətidir: Local Archive-a yazılmır və disk çıxarılanda həmin diskin görüntü, MPR/3D və hesabat cache-i təmizlənir.
