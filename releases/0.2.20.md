# RADAZ 0.2.20

- Local arxiv və PACS-da iki dəfə klik mövcud Viewer-də müayinəni açır, Viewer-i maksimum ölçüdə önə gətirir. Arxiv və PACS pəncərələri kiçildilmir.
- CD/DVD importu görüntüləri daimi Local arxivə yazır və hər hazır görüntünü paralel olaraq Viewer-də göstərir. Piksellər lokal diskdən oxunur, bütün CD-nin bitməsini gözləmək lazım deyil.
- CD çıxarılanda müvəqqəti nüsxələr silinir. Köçürülmüş görüntülər Local arxivdə, Viewer, MPR, 3D və hesabatda qalır. Təkrar import arxivdə eyni faylı çoxaltmır.
- N: neqativ/pozitiv, O: ox, Q: qələm, K: 3D kursor qısayolları və şəffaf fonlu mətn loqosu saxlanılıb.

0.2.15–0.2.17 yeniləmə ekranında qalıbsa, yeni Setup-ı mövcud quraşdırmanın üzərinə açın. Lokal arxiv saxlanılır. Sonrakı yeniləmələr növbəti açılışda tətbiq edilir.
