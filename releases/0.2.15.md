# RADAZ 0.2.15

- Çap önbaxışı: görüntünün özünə zoom, parlaqlıq və kontrast; Tək/Hamısı checkbox-ları; düzgün xana və kağız uyğunlaşması. DICOM və adi çapda eyni dəyişikliklər saxlanılır.
- MPR: axial, coronal və sagittal tam ekranı; sağ kliklə ölçü silərkən təsadüfi böyütmənin qarşısı; tutulabilən lokalizer fırlatma dairəsi.
- Local arxiv/PACS seçimi açıq Viewer-də yüklənir. Birdən çox seçilmiş müayinə bir pəncərədə açılır.
- Yenilənmə pəncərəsi özü yükləmir. Yeni versiya bildirişi, Yenilə düyməsi və ayrıca təsdiq; yükləmə/quraşdırma gedişi və tamamlanma mesajı.
- Digər iş stansiyaları üçün açıq yenilənmə manifesti, GitHub API ehtiyat yolu, 15 dəqiqəlik yoxlama və müvəqqəti xətadan sonra tez yoxlama.

Windows 10/11 x64: **RADAZ-0.2.15-Setup.exe**. Lokal arxiv və lisenziya saxlanılır. Hazır yenilənmə növbəti açılışda tətbiq olunur.

**0.2.9 və daha köhnə versiyalar:** əvvəlki yenilənmə ünvanı əlçatan deyil; bu Setup-ı bir dəfə açın. Sonrakı versiyalar proqram daxilindən görünəcək və təsdiqlə yüklənəcək.
