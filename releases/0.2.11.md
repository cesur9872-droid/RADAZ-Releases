RADAZ 0.2.11: ölçmə və mouse idarəsi, yenilənmə bildirişləri, ayrıca MPR/3D səhifələri və CT sümük görünüşü.

**Windows 10/11 64-bit üçün RADAZ-0.2.11-Setup.exe endirin.** Node.js, Python, DICOM paketləri və FFmpeg daxildir.

- MPR və 3D ayrıca vərəqələrdə açılır; 2D Viewer yerində qalır. Təkrar klik mövcud vərəqəni önə gətirir.
- Eyni seriyanın decode edilmiş piksel buferləri səhifələr arasında kopyalanmadan paylaşılır. MPR/3D açılışında DICOM təkrar decode edilmir. CD çıxarılanda və mənbə seriya dəyişəndə vərəqələr yenilənir.
- CT Bone: fil sümüyü rəngi, dolğun səth, üç işıq mənbəyi, xətti interpolasiya və öndən anatomik başlanğıc görünüş. Qalın kəsitli CT üçün səth pillələnməsi məlumatı göstərilir.
- Balanced rejimində aydın, dənəvər kölgəsiz səth; High/Ultra-da əlavə səth kölgələri. Hərəkət bitəndə final keyfiyyət bərpa olunur.
- MRT üçün ayrıca siqnal intensivliyi rejimi. CT-yə aid sümük presetləri və HU yazısı MRT-də göstərilmir.
- Ölçü və çəkilmiş xətlər incəldilib, ölçü və görüntü məlumatı yazıları böyüdülüb. Xətt üzərində əl kursoru görünür; hover və seçilmiş ölçünün rəngləri ayrıdır.
- Deviasiya iki nöqtə ilə üfüqi xəttə görə bucağı və şaquli hündürlüyü göstərir. Ayaq tağında hündürlük **H**, bucaq **°** ilə yazılır.
- Ox çəkiləndə şərh əlavə etmək, iki kliklə və ya sağ klik menyusundan dəyişmək olur.
- **Ctrl+D** aktiv kəsitdəki bütün ölçüləri və çəkilmiş xətləri silir; digər kəsitlərdəki ölçülər saxlanılır. Qısa sağ klik menyusunda tək ölçünü və cari kəsitdə hamısını silmək olur.
- İlkin 2D/MPR mouse idarəsi: sol düymə WW/WL, orta düymə move, sağ düyməni saxlayıb sürükləmək zoom. 3D-də sol düymə fırlatma, orta düymə move, sağ düymə zoom. Brauzerin standart sağ klik menyusu söndürülüb.
- Yeni versiya bildirişi yükləmə zamanı da görünür. **Yenilənməyə bax** düyməsi mövcud prosesin progressbarını açır; tamamlananda təsdiq mesajı göstərilir.
- 0.2.10-dan **Yardım → Yeniləmələri yoxla → Yenilə** ilə yenilənir. Prosesin gedişi və tamamlanma təsdiqi görünür; yeni versiya növbəti açılışda tətbiq olunur. Lokal arxiv qorunur.

0.2.9 və daha köhnə quraşdırmalarda yeni Setup-ı bir dəfə açın. Source code ZIP hazır quraşdırıcı deyil.

İlkin sınaq buraxılışıdır. Vizual nəticə seriyanın növü, kəsit qalınlığı və ilkin DICOM keyfiyyətindən asılıdır.
