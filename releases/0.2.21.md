# RADAZ 0.2.21

- CD/DVD importu hər görüntünü əvvəlcə daimi Local arxivə yazır, sonra həmin disk nüsxəsindən Viewer-də göstərir. Köçürülmüş görüntülər disk çıxarılandan sonra da qalır.
- Local arxiv, PACS və importdan yeni müayinə açılanda Viewer 1×1 düzülüşə qayıdır. Eyni seriyalar arasında işləyərkən seçilmiş düzülüş saxlanılır.
- Viewer-də Local arxiv və PACS düymələri artıq açıq pəncərəni önə gətirir; axtarış və seçimlər saxlanılır, əlavə pəncərə yaradılmır.
- Arxiv və PACS axtarış sahələri genişləndirilib, sağ tərəfə mətni təmizləmək üçün X düyməsi əlavə edilib.
- DICOM faylları, qovluqlar, ZIP və RAR arxivləri Viewer-in istənilən sahəsinə və Local arxivə sürüklənərək import edilir. RAR açılması oflayn işləyir; ayrıca WinRAR tələb edilmir. Şifrəli və çoxhissəli RAR əvvəlcə qovluğa çıxarılmalıdır.
- Setup Windows istifadəçisi daxil olanda RADAZ serverini, arxiv xidmətini və proqram pəncərəsini avtomatik başladan qısayol yaradır.

Mövcud quraşdırmanın üzərinə Setup-ı açın. Local arxiv və əvvəlki versiyaya geri qayıtma imkanı saxlanılır.
